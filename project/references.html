These are the sources used to build Movie Tracklist.

Movie Data and Images

  • Movie titles, plots, release years, genres, ratings and posters come from the IMDb Top 100 Movies API on RapidAPI. A copy of the response is saved in data/movies.json so the site still works if the API is unavailable.
  • The poster images are served by IMDb from imdb.com and are used here for a student coursework project only.
  • A few of the posters have been taken down by IMDb. Those cards fall back to images/no-poster.png, which was made for this site.
